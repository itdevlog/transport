# Маршрут — веб-обёртка транспорта Екатеринбурга

Лёгкая веб-обёртка над городским транспортным порталом
`маршрут.екатеринбург.рф`. Показывает **когда ожидать транспорт** на
избранных остановках и позволяет ходить по меню
«маршруты → остановки → прогноз» — без карты и без тяжёлого SPA портала.

Сервер обращается к порталу за вас (обходит CORS и прячет токен), отдаёт
браузеру только свой лёгкий JSON-API и статику.

## Возможности

- **Избранное** (главная): сохранённые маршруты и остановки, у каждой
  избранной остановки — живой прогноз прибытия.
- **Каталог маршрутов**: фильтр по виду транспорта, поиск по номеру.
- **Маршрут**: оба направления, список остановок, переход к прогнозу.
- **Поиск остановок** по названию.
- **Остановка**: прогноз по всем маршрутам, авто-обновление ~20 сек.

## Требования

- Python 3 (только стандартная библиотека — **никаких зависимостей и pip**).
- Доступ в интернет к транспортному порталу.

## Быстрый старт

```bash
python3 server.py
```

Открыть в браузере: <http://localhost:8000>

## Конфигурация (`config.json`)

Файл читается при старте; значения по умолчанию совпадают с порталом.

| Ключ | Назначение | По умолчанию |
|---|---|---|
| `portalUrl` | точка входа API портала | `https://xn--80axnakf7a.xn--80acgfbsl1azdqr.xn--p1ai/php/apiRequest.php` |
| `token` | токен клиента портала | `11111111-50b3-4fec-b922-8a50a1d38366` |
| `reg` | код региона | `66002` |
| `wuid` | идентификатор клиента | `marshrut-web` |
| `host` | адрес прослушивания | `0.0.0.0` |
| `port` | порт | `8000` |
| `cacheTtl` | TTL кэша, сек (`routes`, `route`, `stations`, `forecasts`) | `21600` / `21600` / `21600` / `10` |

## Избранное (`favorites.json`)

Создаётся автоматически при первом изменении (запись атомарная). Файл можно
править вручную:

```json
{
  "routes": [ { "id": 1554, "number": "87", "name": "Академика Ландау – Горбольница № 7" } ],
  "stops":  [ { "id": 5830, "name": "Академия тенниса" } ]
}
```

## Развёртывание на Debian

1. Разместить проект, например в `/opt/marshrut`:

   ```bash
   sudo mkdir -p /opt/marshrut
   sudo cp -r ./* /opt/marshrut/
   ```

2. Создать системного пользователя и unit:

   ```bash
   sudo useradd --system --no-create-home --shell /usr/sbin/nologin marshrut
   sudo cp systemd/marshrut.service /etc/systemd/system/marshrut.service
   sudo systemctl daemon-reload
   sudo systemctl enable --now marshrut
   ```

   Проверить: `systemctl status marshrut` и `journalctl -u marshrut -f`.

3. Опционально — nginx как reverse-proxy на `127.0.0.1:8000`:

   ```nginx
   server {
       listen 80;
       server_name marshrut.example;
       location / {
           proxy_pass http://127.0.0.1:8000;
           proxy_set_header Host $host;
       }
   }
   ```
