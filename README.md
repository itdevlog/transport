# Маршрут — веб-обёртка транспорта Екатеринбурга

Лёгкая веб-обёртка над городским транспортным порталом
`маршрут.екатеринбург.рф`. Показывает **когда ожидать транспорт** на
избранных остановках и позволяет ходить по меню
«маршруты → остановки → прогноз» — без карты и без тяжёлого SPA портала.

Сервер обращается к порталу за вас (обходит CORS и прячет токен), отдаёт
браузеру только свой лёгкий JSON-API и статику.

## Возможности

- **Избранное** (главная): сохранённые маршруты и остановки, у каждой
  избранной остановки — живой прогноз прибытия.
- **Каталог маршрутов**: фильтр по виду транспорта, поиск по номеру.
- **Маршрут**: оба направления, список остановок, переход к прогнозу.
- **Поиск остановок** по названию.
- **Остановка**: прогноз по всем маршрутам, авто-обновление ~20 сек.
- **Локальное зеркало каталога**: остановки и маршруты хранятся в SQLite,
  справочные запросы не дёргают портал повторно (см. ниже).

## Требования

- Python 3 (только стандартная библиотека — **никаких зависимостей и pip**).
- Доступ в интернет к транспортному порталу.

## Быстрый старт

```bash
python3 server.py
```

Открыть в браузере: <http://localhost:8000>

## Конфигурация (`config.json`)

Файл читается при старте; значения по умолчанию совпадают с порталом.

| Ключ | Назначение | По умолчанию |
|---|---|---|
| `portalUrl` | точка входа API портала | `https://xn--80axnakf7a.xn--80acgfbsl1azdqr.xn--p1ai/php/apiRequest.php` |
| `token` | токен клиента портала | `11111111-50b3-4fec-b922-8a50a1d38366` |
| `reg` | код региона | `66002` |
| `wuid` | идентификатор клиента | `marshrut-web` |
| `host` | адрес прослушивания | `0.0.0.0` |
| `port` | порт | `8000` |
| `cacheTtl` | TTL кэша, сек (`routes`, `route`, `stations`, `forecasts`) | `21600` / `21600` / `21600` / `10` |
| `catalog` | локальное зеркало: `enabled`, `path`, `refreshSeconds` | `true` / `catalog.db` / `86400` |

### Локальные переопределения (`config.local.json`)

Рядом с `config.json` можно положить `config.local.json` — он **перекрывает**
значения из `config.json`. Это удобно для настроек конкретной машины
(адрес, порт), чтобы `git pull` их не затирал: файл в `.gitignore` и в
репозиторий не попадает.

```json
{ "host": "127.0.0.1", "port": 8091 }
```

Отсутствующий, нечитаемый, битый или не-объектный файл просто игнорируется —
сервис всё равно стартует с `DEFAULTS`.

## Локальное зеркало каталога (`catalog.db`)

Справочные данные портала (остановки, маршруты, связь «остановка→маршруты»)
меняются редко, поэтому сервис держит их в локальной базе SQLite рядом с
`server.py`. Пока зеркало заполнено, справочные эндпоинты (`/api/routes`,
`/api/route`, `/api/stations`, `/api/stop-routes`, `/api/stops`) отвечают из
базы, не обращаясь к порталу. Живыми остаются только прогноз и данные борта.

- **Первое наполнение** запускается автоматически в фоне при старте
  (если база пуста). Полная пересборка — порядка сотни запросов к порталу
  (~1–2 минуты), поэтому она идёт в отдельном потоке и не блокирует сервер.
- **Обновление** — раз в `refreshSeconds` (по умолчанию сутки), фоновым
  потоком, а также вручную: `POST /api/refresh`.
- **Статус** — `GET /api/catalog` → `{"enabled", "building", "lastRefresh", "counts", "lastError"}`.
- **Отключить** — `"catalog": {"enabled": false}` в `config.json`: тогда всё
  работает напрямую с порталом, как раньше, и `catalog.db` не создаётся.
- Если база пустая или повреждена, сервис молча отвечает из портала — падения
  нет. Файл `catalog.db` в `.gitignore`.

## Избранное (`favorites.json`)

Создаётся автоматически при первом изменении (запись атомарная). Файл можно
править вручную:

```json
{
  "routes": [ { "id": 1554, "number": "87", "name": "Академика Ландау – Горбольница № 7" } ],
  "stops":  [ { "id": 5830, "name": "Академия тенниса" } ]
}
```

## Развёртывание на Debian

Подробная рабочая инструкция — в [DEPLOY.md](DEPLOY.md) (клонирование из
git, пользователь `marshrut`, systemd-юнит, reverse-proxy на Caddy/nginx,
локальный `config.local.json`). Коротко:

```bash
sudo useradd --system --no-create-home --shell /usr/sbin/nologin marshrut
sudo git clone https://github.com/itdevlog/transport.git /opt/transport
sudo chown -R marshrut:marshrut /opt/transport
sudo -u marshrut python3 -c "import shutil; shutil.copy('/opt/transport/config.json','/opt/transport/config.local.json')"
# в config.local.json задать host/port под свою машину
sudo cp /opt/transport/systemd/marshrut.service /etc/systemd/system/marshrut.service
sudo systemctl daemon-reload && sudo systemctl enable --now marshrut
```

## Обновление

```bash
sudo git -C /opt/transport pull
sudo systemctl restart marshrut
```

`config.local.json` и `favorites.json` не отслеживаются git и переживают
обновление без конфликтов.
